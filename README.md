# ConsultaRe

**ConsultaRe** is a **customer relationship management (CRM)** and sales pipeline system specialized in **financial consulting and credit restructuring services**. Created to help consultants manage leads, track client progress, and optimize workflow.

**Access here:** [ConsultaRe Online](https://consultare.vercel.app/)

## Features ✨

ConsultaRe provides essential tools for managing the entire client lifecycle:

* **Lead/Client Management**: Add, view, and edit all client data in an organized way.
* **Sales Pipeline**: Track clients through different statuses:
    * `New`
    * `In Proposal`
    * `Hired`
    * `Post-Sale`
    * `Finished`
    * `Archived`
* **Client Details (Sidebar)**: Quick view and edit of client information, including **Consultation**, **Proposal**, and **Down Payment** data.
* **Client Actions**: **Archive** and **Unarchive** clients to keep the main list clean.
* **Status Filter**: Filter the client list to view only leads in a specific status.
* **Responsive Design**: Interface adaptable for desktop and mobile devices.
